## Problem statement

You are creating a simple C++ program for a teacher to calculate a student's result.

Your program should:

1. Take input: Ask for the student's name, roll number, and marks in 3 subjects.

2. Use data types: Store the name as a `string`, roll number as an `int`, and marks as integers.

3. Use arrays: Store the three subject marks in an array.

4. Use loops: Use a loop to input the marks and calculate the total and average.

5. Use if-else: Determine whether the student has passed or failed. The student must score at least 35 marks in every subject to pass.

6. Use switch case: Display a menu:

   * `1` — Display student details

   * `2` — Display total and average

   * `3` — Display pass/fail result

7. Use functions: Create separate functions for calculating the total and displaying the result.

8. Use pass by reference: Create a function that updates a student's bonus marks by adding 5 marks to one subject.

9. Use STL pairs: Store the roll number and total marks together using a `pair`.

10. Use time complexity: Think about the time complexity of the loop that processes the three subjects.

## Sample input

```
Enter student name: Rahul
Enter roll number: 101

Enter marks in 3 subjects:
78
65
82

Choose an option: 2
```

## Expected output

```
Total marks: 225
Average marks: 75
```
